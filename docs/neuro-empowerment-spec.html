EL-SYSTEMA · 場 → 身体・脳

神経賦活設計 全 web 楽器を、既存の音に触れずに「足すだけ」で神経・自律・身体へ働きかける、エビデンスベースの並列刺激プラットフォームへ拡張する仕様。

注意・覚醒（γ） 自律・鎮静（HRV） 睡眠・記憶固定（徐波） 運動・歩行（律動） 感覚・平衡（確率共鳴）

01 — 設計原理

刺激は既存の音を奪わない。並んで鳴る。

EL-SYSTEMA の共有基盤（el-systema-control.js）は「既存器の音源・UI を一切変えない＝足すだけ」を原理とする。刺激層もこれに従い、自前のオシレータを持つ独立した声として各楽器の master bus へ connect するだけにする。

作品の揺らぎと刺激の固定が両立

刺激は既存信号を変調しないので、楽器本来の生成的な揺らぎを損なわない。両者は同じ信号を奪い合わず並列に足される。

リバーブ非経由が自動保証

fx.output と並列に足すため、残響で包絡線が平滑化されない。40Hz の変調深度が耳に届く時点で保たれる。

灯を消せば完全に元通り

停止は disconnect するのみ。楽器の音・UI・プリセットは一切変わらない。全楽器へ同じ流儀で載る。

04 — 横断機能

装置としての信頼性を支える共通層

anchor / field の分散モデル

40Hz は端末間で位相同期不能（周期25ms＜ジッタ）。1台の anchor 内に閉じ、0.1Hz 呼吸のみ epoch 配布＋各端末のローカル時計で同期。場が同じ呼吸をする。

包絡線モニタ＝信頼性の核

各楽器の刺激出力を整流→LP→専用 FFT で復調し「実際に 40.0Hz / 深度○%」を常時表示。表示値ではなく実測値で装置の妥当性を担保する。

祭祀語彙の統一 API

灯 / 脈 / 息 / 眠 / 体 / 相 / 律 / 揺 / 光 を setParam と maneki(セッション宣言) で制御。hub の macro・祭文（応答ルール）から全楽器を一斉演奏。

生体入力への発展（閉ループ）

マイク＝呼吸、カメラ PPG＝心拍を任意入力に。呼吸ペーサーを個人の共鳴周波数へ、拍を心拍・歩調へ適応させる閉ループ生体フィードバックを将来層として設計。

05 — 安全・統治

効能を語らず、事実と証拠だけを置く

医療的効能表現の禁止

「治癒・治療・効果」等を UI/README/meta に書かない（薬機法）。「研究文献に基づく刺激パラメータ／実験装置」に留め、各周波数に出典タグ [GENUS/ASSR]・[HRV]・[徐波/CLAS] を付す。

禁忌の事前表示

てんかん・光過敏症、心疾患、ペースメーカー、妊娠中、内耳疾患は使用前に医師へ相談。光フリッカは既定オフ・深度上限・明示オプトイン。

曝露の管理

マスター段 Limiter(-6dB)、推奨聴取レベル表示、セッションタイマー（既定60分・フェード各30秒）。無人検知には自己観測 kehai を使わない（原理的に不可）。

証拠主義

採用は査読研究の刺激パラダイムのみ。ソルフェジオ／シューマン共振等の非エビデンス周波数は追加しない。主張は再現可能な事実の記述に限る。

06 — 展開順

動くものから、場全体へ

息（0.1Hz）を全楽器へ

独立した声ゆえ既存に触れず、分散同期も余裕を持って成立。体感が最も明確で最速に「場が同じ呼吸をする」状態を作る。共有 assr.js を全 public/shared へ配布し登録1行を追加。

包絡線モニタを各楽器へ

次に作るものを検証する道具を先に置く。刺激の妥当性を実測で見える化。

脈（40Hz）を anchor 系ドローンへ

HADŌ庭・PLANARIAN・ORI 等。モニタで実測しながら搬送・深度・波形を確定。

律（RAS）を拍系へ

BEAT/HEN/STONE/MYCORRHIZA にケイデンスロック・タップ追従・漸進テンポ。

揺（確率共鳴）をノイズ系へ・眠を睡眠背景へ

DUST/CELLNOISE/PARTICLE/OCEAN/MOSS に 1/f 較正・SR 掃引・徐波バースト。

光（SSVEP）を幾何系へ（安全最優先）

GEO/OSC に視覚フリッカ。光過敏スクリーン・深度上限・オプトインを実装してから点灯。

生体入力の閉ループ化

呼吸(マイク)・心拍(PPG)を取り込み、共鳴呼吸・RAS を個人へ適応。研究文脈への接続点。

免責　本仕様が扱うのは研究文献に基づく感覚刺激パラメータを用いた実験装置であり、医療機器ではない。診断・治療・治癒を目的とせず、効能を主張しない。使用は各人の判断と、必要に応じた医師への相談のもとに行う。
